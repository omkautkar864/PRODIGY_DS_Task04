# 📘 Task 4 - Sentiment Analysis & Visualization

## 📌 Overview
This project analyzes and visualizes sentiment patterns in social media data to understand public opinion and attitudes toward specific topics or brands.  
The notebook demonstrates text preprocessing, sentiment classification, and visualization techniques.

---

## 📂 Dataset
- Source: Task 4 Dataset (GitHub)  
- Contains social media text entries with sentiment labels (positive, negative, neutral).  
- Can be extended to other datasets (Twitter, Reddit, YouTube comments).

---

## ⚙️ Requirements
- Python 3.8+  
- Jupyter Notebook  
- Libraries:
  - pandas, numpy  
  - matplotlib, seaborn  
  - nltk, textblob  
  - scikit-learn (optional, for ML models)
